# F103 真实双 IMU 无线回传实测结果

2026-11-05，在用户明确授权新固件烧录、无线测试，以及后续手动断电上电后，**真实双 IMU → F103 → 裸 24L01P → USB RX → 开发电脑链路通过首轮低速台架验证**。树莓派未参与本轮，连续运行版本与正式频率仍待确定。

## 完整交付核对

| 项目 | 实测结果 |
|---|---:|
| MCU 完成的整包 | 100 |
| USB RX 收到并独立 CRC 校验通过的整包 | 100 |
| 前 IMU 包 | 50 |
| 后 IMU 包 | 50 |
| 原始 USB 字节 | 3200 |
| MCU 发送成功的 16 字节片段 | 200 |
| MCU 失败片段 / SPI 错误 / 编码错误 | 0 / 0 / 0 |
| USB 非法帧 / 丢弃字节 / 尾部残片 | 0 / 0 / 0 |
| UART 硬件错误 / 接收队列丢失 | 两路均 0 / 0 |
| 本次启动标识 | 2 |
| 最终固件故障标志 | 0 |
| 最终无线状态 | 4，已结束发送并发出掉电命令 |

前路实际无线更新约 **0.829 Hz**，后路约 **0.828 Hz**。两只 IMU 仍按各自约 25 Hz 输出，MCU 保留最新有效帧并公平轮询发送；遥测分两段、相邻段间隔至少 300 ms。这里验证的是低速上报链路，不是每路 25 Hz 无线传输。

每路序号缺口累计 1430，来自有效采集帧中未逐一上报的样本；不能把它称为无线丢包。无线完整交付根据 MCU 完成 100 包与电脑实收 100 包独立对照。这个有限台架窗口中无完整无线包缺失，不等于所有距离、干扰和速率条件下保证不丢包。

## 写入与恢复过程

首次写入 6896 字节无线固件时，st-flash 完成镜像写入校验，但复位后 hot-plug SWD 目标标识为零，USB RX 收到 0 字节。工具停止，没有自动重刷。完整失败记录保留在 `captures/f103_radio_20261105/first_run/`。

用户确认板卡红灯和 IMU 指示灯亮后，按说明拔除板卡 USB 供电和 ST-Link USB，等待 10 秒后恢复原接线供电。此次没有重新烧录、修改信号线、保护或选项字节。SWD 随后读回设备 ID 0x0412、Flash 32 KiB，并取得 boot_id=2 的真实无线数据。

**已知限制：本次烧录后即时重连失败，完整断电上电后恢复，根因尚未确定。** 不将一次恢复表述为已永久修复；不能把调试器枚举、指示灯亮或 st-flash 写入成功单独当作新固件运行正常。NRST 未连接是此前日志中的事实，但还不能据此认定是唯一原因。

- 前七个页以外、启动日志以前的中间区域 `[7168, 30720)` 与本轮烧录前备份一致。
- 末尾 2 KiB 启动日志中可见有效 counter/反码记录 **1、2**，与本轮第二次上电的无线启动编号一致。
- 本次完整读回 SHA-256：`7bf04e50f64c3336f16adb161143b5ef371a7471cadcacee8a90e40f7915064a`。

原始烧录备份与日志：`captures/f103_flash/20261105T044027.874015Z/`。最终稳定读回和核对：本次成功目录下 `flash_readback/`、`flash_verification.json`。

## 证据与当前状态

成功目录：`captures/f103_radio_20261105/power_cycle_recovery/`。

- `rx.jsonl`：每包前后身份、源序号、源端 UART 收帧时间、主机接收时间、测量值和完整 `wire_hex`。
- `serial.bin`：原始 3200 字节；SHA-256 `b51fde90654fca39514de239671a082565dc3caac468dea3fdf6c0a64f9a3980`。
- `recovered_diagnostic.json`、`final_diagnostic.json`：发送过程中及发送结束后的 MCU 状态、原始 SRAM 快照和独立统计。
- `summary.json`：主机重算 CRC、启动编号匹配、MCU 整包数与实收数对照、各路上报频率和验收结果。

固件发送窗口已自行结束。确认最终无线状态为已结束后，电脑只读接收器通过 SIGINT 正常关闭，原始字节缓冲已落盘。最终接收状态中的 fresh=false 是主动结束发射后超过新鲜度门限的正常结果，不是本轮通信失败。

MCU 保持运行当前诊断版本：继续接收 IMU，当前不再发射；下次完整上电或复位会再次按已烧录的约 5–65 秒发送窗口运行。未向 IMU 发送配置命令，未访问行驶、转向或其他车辆执行器。

外设仍按用户接法使用板载 3.3V。发送期间数据与错误统计通过，但没有独立测量电源电压/电流、最大距离、长期稳定性或安装外参。后续首先把 USB RX 转到树莓派验证接收端，再按用户决定的频率准备正式持续回传配置。
