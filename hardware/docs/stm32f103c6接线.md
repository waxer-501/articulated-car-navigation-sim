# STM32F103C6T6A 双 IMU 采集接线（2026-11-04）

2026-11-05 最新结果：固件已获授权烧录，两路真实 IMU 在约 25 Hz 下完成 30 秒静止采集，新增 UART 错误与队列丢失均为零。无线保持关闭；见 [实测记录](f103双IMU实测_20261105.md)。

2026-11-05 用户确认按下表接完所有线、IMU RX 也已连接，外设使用板载 3.3V。电源能力尚未实测；本页关于独立稳压电源的说明保留为供电建议，不代表已安装外部电源。接收诊断固件已烧录、原 Flash 已备份；首次测试范围见 [测试说明](f103首次采集测试.md)。

用户已将采集板改为照片中的 STM32F103C6T6A 最小系统板，MC02 方案停止作为当前接线依据。范围仍是两只 IMU406 采集与无线回传，不接车辆运动接口。

## 当前证据

- 用户报告最小系统板与 ST-Link 均已接电脑，SWD 已接线。
- 本机 USB 枚举看到 `0483:3748 ST-LINK/V2`。初次读取因 USB 权限失败；用户随后安装准备好的权限规则，再执行 `st-info --probe --hot-plug --freq=100` 成功：ST-Link V2J45S7、设备 ID `0x0412`（F1 Low-density）、Flash 32768 字节、页大小 1024 字节，工具报告 SRAM 10240 字节。与用户所报 C6 规格一致，不代表读取到完整型号后缀，也没有做 SRAM 容量测试。未烧录或请求复位。原始结果保存在 `captures/stlink_20261104/hotplug_probe.txt`。
- 照片可见 Micro-USB 插座和标为 A0…A15、B0…B15 的引出孔。型号以用户报告为准，照片不足以读清芯片全部丝印。两侧看起来尚未焊排针，应先确认背面；不能靠杜邦针松插裸孔维持可靠接触。
- ST 官方数据手册 STM32F103x4/x6（DocID15060 Rev 7，第 11 页表 2）列 C6 为 32 KiB Flash、10 KiB SRAM，两路 USART、一路 SPI。第 26–27 页表 5 给出下面的复用功能。不能采用常见 F103C8 的 64 KiB/20 KiB 或 USART3 配置。

来源：https://www.st.com/resource/en/datasheet/stm32f103c6.pdf

## 引脚分配

下表 A10 指 PA10，以板上丝印为准，不按照片左右或杜邦线颜色辨认。USART 均使用默认映射。

| 设备信号 | 最小系统板引脚 | 配置/用途 |
|---|---|---|
| 前 IMU406 TX1（手册 pin 7） | A10 / PA10 | USART1_RX，115200 8N1 |
| 后 IMU406 TX1（手册 pin 7） | A3 / PA3 | USART2_RX，115200 8N1 |
| 两只 IMU GND（pin 12） | G / GND | 与 MCU、无线模块共地 |
| 两只 IMU 3.3V（pin 10） | 经核实的稳压 3.3V | 不接板上 5V，不默认板载稳压器容量足够 |
| 两只 IMU RX1（pin 1） | 不接 | 初次只采集，不发送配置 |
| 裸无线模块 GND | G / GND | 共地 |
| 裸无线模块 VCC | 经核实的稳压 3.3V | 不能接 5V |
| 裸无线模块 SCK | A5 / PA5 | SPI1_SCK |
| 裸无线模块 MISO | A6 / PA6 | SPI1_MISO |
| 裸无线模块 MOSI | A7 / PA7 | SPI1_MOSI |
| 裸无线模块 CSN | A4 / PA4 | GPIO 输出，初始高 |
| 裸无线模块 CE | B0 / PB0 | GPIO 输出，初始低 |
| 裸无线模块 IRQ | 暂不接 | 固件轮询状态 |
| ST-Link SWDIO | PA13 / SWDIO | 保留调试接口 |
| ST-Link SWCLK | PA14 / SWCLK | 保留调试接口 |
| ST-Link GND | G / GND | 共地 |

PA9、PA2 预留为 USART1_TX/USART2_TX，初次不接 IMU。C6 没有 UART7，也不将 B10/B11 当作 USART3 使用。

无线连接对象是从 USB TX 底板取下的 8 针射频模块；不能把 USB TX 底板通过 Micro-USB 转接器接到本板，也不能让底板 MCU 与 F103 同时驱动模块 SPI。裸模块具体针脚方向仍需按模块照片和厂家图核实。

## 接线和供电条件

先断开 USB 和外部电源再改线。若最小系统板已用自身 USB 供电，ST-Link 只连接 SWDIO、SWCLK、GND；如调试器确有 VTref 输入，按该型号说明接参考电压。不要再把调试器的 3.3V/5V 电源输出与板上电源并联。

两只 IMU 手册典型电流合计约 120 mA，另有 MCU 和无线模块负载。用户当前采用板载 3.3V；本轮静止接收未观测到重启或 UART 错误，板载稳压器型号、实际温升和可用电流仍未核实，不能据此证明无线发射负载下供电稳定。独立稳压 3.3V 是可选供电方案，使用时保持共地，不与另一个 3.3V 电源输出直接并联。无线模块附近按厂家建议加滤波电容，SPI 线尽量短。

BOOT0 正常运行置 0；不要为 ST-Link 烧录随意改动跳帽。照片不能可靠确认当前跳帽所选状态。

## 软件与验证边界

已有纯 C IMU 解码和遥测封包可继续使用，MC02 的 H7 启动文件、时钟和 HAL 不能直接用于 F103。当前已完成独立 Cortex-M3 启动、32 KiB/10 KiB 链接配置和 USART1/2 接收诊断固件的构建、烧录及真实双 IMU 采集，SPI1 无线驱动仍待后续实现。

ST-Link USB 访问、hot-plug SWD 标识读取及获授权后的诊断固件烧录已通过。真实双 IMU UART 采集通过；SPI 无线、USB RX 回传及树莓派接收仍待独立验证。
