## 无线模块可以直接用杜邦线接 SPI

目标是连接 8 针射频模块本体，而不是要求 MC02 给 USB TX 测试底板提供 USB 主机接口。

| 无线模块引脚名称 | MCU 端功能 | 说明 |
|---|---|---|
| VCC | 经核实的 3.3 V 电源 | 模块本体不能接 5 V；具体电源引出点待实物确认 |
| GND | GND | 必须共地 |
| SCK | SPI SCK | 时钟 |
| MOSI | SPI MOSI | MCU 发到模块 |
| MISO | SPI MISO | MCU 读取状态和寄存器；即使只发无线数据也需要 |
| CSN | 独立 GPIO | SPI 片选，低有效 |
| CE | 独立 GPIO | 射频使能控制 |
| IRQ | 暂不连接，或另一个输入 GPIO | 首版可通过 SPI 轮询状态 |

这是按信号名称列的逻辑表，**不是模块针脚编号或 MCU 实物排针编号**。应按模块丝印与厂家图核对方向。杜邦线适合初步台架连接，尽量短；先用较低 SPI 时钟（工程起点不高于 1 MHz），验证后再调整。

若无线模块目前插在 USB TX 底板上，连接 MCU 前需要先断电并从该底板取下，使 MCU 成为唯一 SPI 主机。若是焊接不可拆结构，应先核对照片/电路，不能直接把另一组 MCU 输出并联上去。

## 两路 IMU 与烧录接口独立

- 前 IMU：IMU406 的 TX1 接 UART1 的 MCU RX；后 IMU同理接 UART7 的 MCU RX。
- 两只 IMU406 均为 3.3 V 供电，共地；初次被动采集不接 IMU RX1，不发送配置指令。
- ST-Link 使用 SWDIO、SWCLK、GND 及目标电压参考连接，烧录不依赖开发板 USB。
- MCU 自己仍须正确供电；ST-Link 的目标电压参考线不能未经核实当作整套 IMU/无线模块的供电源。
